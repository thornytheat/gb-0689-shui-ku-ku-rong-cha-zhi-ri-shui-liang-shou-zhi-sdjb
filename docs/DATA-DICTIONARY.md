# 水位与水量定义

id、station为字符串。time含时区，统一UTC，日账在+08:00午夜拆分。level单位m；inflow/outflow单位m3/s或L/s，归一m³/s；空值不等于零。负流量与曲线外水位隔离。
curve为[[水位,库容],...]，水位及库容必须严格递增，库容非负，单位m与m³。只对范围内水位分段线性插值，端点允许。
同站同刻按version最高记录采信，同版不同值全部隔离。重复旧版有独立证据。输入=采信+隔离；原始行号保留。
相邻观测间以梯形积分计算流量体积，超过max_gap_hours则不插补。日界处先线性插出流量与水位，再分别积分及按曲线换算库容。日账是已覆盖时段的收支，覆盖不足24h始终待补测。
日收支差=库容变化-入库+出库，绝对值超过tolerance_m3需复核。缺测优先于超差。无蒸发降雨模型，差额不自动认作漏损。
数值为Decimal字符串，日切与整段积分容许1e-9m³以内十进制除法尾数。规则参数和输入摘要参与幂等ID；批次原子保存，复核版本冲突返回409。

原始到达序小于此前最大事件时刻的测次标记arrival=迟到，仍保留并按事件时间排序积分，迟到不会推进水位回退。

## 曲线复测复核影响（M6）

库容曲线局部复测后，历史水文值（水位、流量、测次）不变，仅库容换算曲线发生修订。对已保存批次以同一批 `flows` 在新旧曲线上分别重算日账，逐日期比对库容变化与裁决结果，生成复核影响清单（`curve_impacts` 表，接口 `GET/POST /api/m6/impacts`，复核页 `/m/6` 展示）。

- 影响判据：新曲线下的日库容变化与原值相差超过 1e-9 m³ 即 `affected=true`；日账只取决于日界端点库容，内部节点改值但端点库容不变时不误判。
- 重开判据：`affected=true` 且该批次原核定 `review=通过` 时 `need_reopen=true`。待复核、退回批次的日账无已通过效力，受影响也不标记重开，但不得继续按已通过处理。
- 未受影响日期的原批准继续有效；受影响日期在清单中给出新旧库变、收支差、裁决（PASS/GAP/LIMIT，越界时为 CURVE/无法换算）及该日水位命中的新旧曲线差异区间。
- 曲线差异按两条曲线节点并集切分整段区间，附区间端点的新旧库容与差值；新曲线覆盖不到历史水位时登记 range_notes，对应日期标记无法换算而非整体失败。
- 幂等：清单以 `(base_run_id, new_curve_fingerprint)` 唯一约束，指纹为曲线点 JSON 的 sha256；同一曲线修订重跑复用既有清单（HTTP 200，`created=false`），不同修订各自独立留痕。
- 失败保留旧版：影响清单先在内存完整计算，成功后才单行原子写入；曲线校验或换算抛错时不触碰既有清单。
